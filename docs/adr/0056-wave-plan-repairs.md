# Give one Agent the Plan findings from a finished wave

This revises the Plan follow-up in ADRs 0053 and 0055. Lane Agents still
work independently on the package's pinned Authoring wave. A finished
submission is usable as draft evidence. Accepting a lane report and
accepting the resulting Plan remain separate human decisions.

After the wave's lane jobs finish, the service groups the reports that call
for Plan repair. One claimable Plan job pins the Plan version, source
report identities and findings. A workflow version has at most one active
consolidated repair. The Agent returns one validated candidate and an
explanation for each finding, including missing evidence. The Engineer
reviews the changes and can accept or send the saved proposal back with
feedback. Confirmation binds the latest submission to its exact Plan basis.

Historical lane drafts retain their original proposals and decisions. The
Engineer can request an Agent reconciliation against a current Plan with
the same approved evidence. The job includes compatible edits and competing
values, so resolving them is part of the Agent's assignment. Repeating the
request opens the same job. A new Plan still goes through the existing
approval and regeneration flow.
