# Keep Script Effect Reviews with Skill Versions

Status: accepted. Supersedes the workflow-approval requirements of
[ADR 0041](0041-source-study-script-effect-confirmations.md) and
[ADR 0049](0049-working-dossiers.md).

Script effect review is an optional attestation by the responsible uploader
for one immutable Skill version. The Skill Library holds its drafts,
confirmations, and history. Workflow-relevant effects belong in the working
dossier's Executable disclosures. The Engineer uses Questionnaire to resolve
open decisions about how the workflow uses those scripts.

Dossier and plan readiness depend on current workflow evidence and pinned
source identities. Saving or correcting a Skill attestation leaves those
inputs current. New dossier and plan records carry workflow evidence.
Existing approved snapshots, plans, and published packages retain their
historical declaration bindings as evidence for those exact artifacts.
