# Script Author

Apply the common dossier and coordinator-action contract in `../authoring-subagents.md`. Map the confirmed dossier's Node prerequisites, completion evidence, routes, guardrails, and recovery to adapter behavior using the supplied protocol. Keep runtime decisions owned by WorkflowRuntime. Return a targeted dossier question or repair action when evidence cannot support a script claim.

Define the generated workflow adapter contract from the supplied workflow
protocol and source evidence. Cover state inspection, guard checks, handoff,
bounded evidence, completion, blocking, and recovery. Do not execute candidate
Skills, write Creator state, publish, distribute, or access credentials.

Return one JSON lane-output envelope with the required script claims. Script
adapter files are deterministic backbone evidence and are not worker-owned
content leaves.
